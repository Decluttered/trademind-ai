# Douyin Shop Product Draft Creation Idempotency Design

## Key Constraints

- `commit=false`: only creates a draft; does not auto-publish
- `start_sale_type=1`: keeps the item in an unpublished (off-sale) state

## Idempotency Key

```
douyin-product-draft-create:{shopId}:{productDraftId}:{publishVersion}
```

Generated by the `DouyinProductDraftCreate` function in `idempotency/keys.go`.

## Flow

```
1. Acquire idempotency key
   DecisionAlreadySucceeded → reuse the existing platform_product_id
   DecisionInProgress → wait/poll

2. Call product.addV2 (commit=false)

3. Success
   → Complete idempotency record
   → Persist platform_product_id to product_publications

4. Timeout (unknown_result)
   → tryRecoverDouyinDraftFromPlatform(outer_product_id)
     → Query the platform via product.detail?outer_product_id
     → Found → treat as success, Complete
     → Not found → ManualReviewRequired=true
   → Fail idempotency record (retryable=false)

5. Platform validation failure (validation / contract_mismatch)
   → Fail idempotency record (retryable=false)
```

## Testing Convention

Draft creation tests use the `testdata/douyin/product_draft_create.json` synthetic fixture.
Real E2E testing requires real credentials and is currently deferred.
